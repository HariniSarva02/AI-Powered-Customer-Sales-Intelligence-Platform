# AI-Powered Customer & Sales Intelligence Platform

Developed an end-to-end retail analytics project to explore sales performance, profitability, customer behavior, and product returns using Superstore business data.

**Project Highlights**
- Cleaned and validated retail data using Python and Pandas.
- Analyzed sales trends, product performance, regional performance, and return patterns.
- Developed an interactive Streamlit dashboard with Home, Sales Analysis, Returns Analysis, and Customer Intelligence sections.
- Presented business metrics and visual insights to support data-driven decision-making.

**Technologies:** Python, Pandas, SQL, Streamlit, Power BI, Data Analytics
