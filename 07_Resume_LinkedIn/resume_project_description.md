# Resume Project Description

## AI-Powered Customer & Sales Intelligence Platform

**Technologies:** Python, Pandas, SQL, Streamlit, Power BI, Data Analytics

- Developed an end-to-end customer and sales intelligence platform using retail Superstore data to analyze sales performance, profitability, returns, and customer behavior.
- Cleaned and prepared business data using Python and Pandas, performing data validation, quality checks, and preprocessing.
- Analyzed sales trends, product performance, regional performance, and return patterns to identify actionable business insights.
- Built an interactive Streamlit dashboard with dedicated Sales Analysis, Returns Analysis, and Customer Intelligence sections.
- Created visualizations and business performance metrics to support data-driven decision-making.
